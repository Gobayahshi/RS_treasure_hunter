관리자 로그인

SKT 총괄은 모든 기능을, SKT 직원은 조회와 대리점 관리자/직원 구분만 할 수 있습니다.

SKT 직원 계정(조회 전용)으로 로그인했습니다. 데이터를 바꾸는 버튼은 보이지 않습니다. 영업사원의 대리점 관리자/직원 구분은 아래 영업사원 목록에서 바꿀 수 있습니다.

SKT 직원 계정

SKT 직원은 전국 데이터를 조회만 합니다. 재고 화면(/inventory)과 이 관리 화면에 같은 아이디로 로그인합니다.

재고 엑셀

재고현황 엑셀은 대리점 계정으로 재고 화면에서 올리세요. 올리면 그 대리점 이전 재고는 교체됩니다.

보물 심기

지도를 눌러 위치를 지정하거나, 현재 위치/위경도를 직접 입력하세요. 포인트는 이 보물에만 적용됩니다.

지도를 클릭하면 그 자리에 보물이 심어집니다.

심은 보물

검토 대기 방문

GPS 신뢰점수가 낮아 자동 승인되지 않은 방문입니다. 승인하면 자동 승인과 같은 기준으로 포인트가 적립됩니다.

기본 포인트 · 통계

엑셀 스폰 보물(일반/레어)의 기본 포인트입니다. 위에서 직접 심은 보물은 각자 지정한 포인트를 씁니다.
