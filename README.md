# RS-Treasure Hunter

대리점 영업사원이 담당 판매점을 실제로 방문하면 GPS 기반 위치 인증을 통해 "보물"을 획득하고, 포인트/랭킹에 따라 리워드를 받는 게이미피케이션 방문 인증 시스템입니다.

**Python(Flask) + SQLite + 순수 HTML/JS** 만으로 구성된 경량 웹 앱이라 설치·실행이 매우 빠릅니다. Node.js나 별도 DB 서버가 필요 없습니다.

## 프로젝트 구조

```
webapp/
├── app.py              # Flask 서버: API 라우트 + 정적 페이지 서빙
├── db.py                # SQLite 스키마 및 커넥션 헬퍼
├── confidence.py         # ★ GPS 위치 인증 부정행위 방지 규칙엔진 (R1~R9)
├── requirements.txt
└── static/
    ├── index.html        # 영업사원용 앱 (로그인/지도/방문인증/포인트)
    ├── admin.html         # 관리자용 화면 (판매점 등록/보물 스폰/랭킹)
    ├── css/style.css
    └── js/
        ├── app.js
        └── admin.js
```

## 핵심 컨셉

1. 관리자가 `/admin` 페이지에서 판매점 주소와 좌표를 등록한다.
2. "보물 스폰 실행"을 누르면 보물이 없는 매장에 보물이 생성된다. 오랫동안 미방문한 매장일수록 레어(rare) 등급이 부여된다.
3. 영업사원이 앱(`/`)에서 **엑셀에 등록된 고유ID**로 로그인 후, 브라우저 GPS로 **본인 소속 대리점 판매점**의 근처 보물을 거리순으로 확인한다.
4. 매장 반경(150m) 내에서 "보물 캐러가기"를 누르면 60초간 위치 샘플을 수집하는 "방문 인증 세션"이 시작된다.
5. 서버는 수집된 샘플에 아래 규칙을 적용해 신뢰도 점수(0~100)를 계산하고, 자동 승인/관리자 검토/자동 반려로 분기한다.
   - Mock Location 탐지, 반경 체크, GPS 정확도, 체류시간, 이동 일관성, 텔레포트(비정상 이동속도) 탐지, 중복 인증 제한, 디바이스 바인딩, 근무시간 외 이상 패턴
6. 승인되면 포인트가 적립되고 보물이 사라진다(claimed). 포인트는 `/` 앱의 "포인트" 탭에서, 랭킹은 `/admin`에서 확인할 수 있다.

자세한 규칙은 `webapp/confidence.py`의 `RULES_CONFIG`와 `evaluate_visit_session()`을 참고하세요.

## 시작하기

### 사전 준비물
- Python 3.9 이상

### 실행

```bash
cd webapp
pip install -r requirements.txt
python app.py
```

브라우저에서:
- 영업사원용 앱: http://localhost:5000/
- 관리자 화면: http://localhost:5000/admin

첫 실행 시 `webapp/rs_treasure.db` (SQLite 파일)가 자동 생성됩니다. 초기화하려면 이 파일을 삭제하고 다시 실행하세요.

### 사용 순서 (데모/테스트)

1. `/admin` 에서 **양식 다운로드** 후 대리점/영업사원/판매점 엑셀을 올린다. (GPS 테스트는 "현재 위치로 채우기"로 판매점 좌표를 넣는다)
2. `/admin` 에서 "보물 스폰 실행"을 눌러 보물을 생성한다.
3. `/` 앱에서 엑셀에 있는 **고유ID**로 로그인한다.
4. 브라우저가 위치 정보 접근을 요청하면 허용한다 (HTTPS가 아닌 `http://localhost`는 예외적으로 위치 API가 허용되지만, 실기기에서 접속할 경우 HTTPS 또는 `http://<로컬IP>`가 필요할 수 있다).
5. 근처 보물 목록에서 반경 내 매장의 "보물 캐러가기"를 눌러 60초간 대기하면 자동으로 인증이 완료된다.
